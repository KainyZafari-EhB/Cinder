# Cinder

A conversation-first IDE built around Claude. You start from your conversations, not from a folder: open one and its project opens with it. Claude reads and changes your code, and every change shows up as a diff you can keep or undo.

Cinder is a fork of [VS Code](https://github.com/microsoft/vscode) (Code - OSS), kept as a small set of changes on top of a pinned VS Code release.

## What's in it

- **Home screen**: "What's up?", a message box with a project picker, and your recent conversations across all projects.
- **Conversations open projects**: clicking a conversation opens its project window and continues the conversation there.
- **Claude in the side bar**: streaming replies, tool activity, permission prompts for commands, Stop.
- **Review every change**: each file Claude edits opens as a diff, with Keep and Undo.
- **Look and feel**: calm and warm, close to the Claude desktop app: Inter for the interface, Source Serif 4 for Claude's replies, JetBrains Mono for code. Themes: Cinder Dark (warm charcoal and ember orange), Cinder Midnight and Cinder Light.

Claude runs through the [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) with your own Anthropic API key (Command Palette → "Cinder: Set Anthropic API Key"). Conversations are stored as Claude Code sessions, so the ones you had with Claude Code in a terminal show up too.

## Repo layout

| Path | What it is |
| --- | --- |
| `upstream.json` | The VS Code release Cinder is built on |
| `product.json` | Name, app IDs and the Open VSX marketplace, merged into VS Code's |
| `patches/` | The small changes to VS Code itself (default theme, fonts, motion) |
| `extensions/cinder-agent` | Home screen, conversations, Claude integration, diff review |
| `extensions/cinder-themes` | The color themes (generated by `generate.mjs`) |
| `fonts/`, `branding/` | Workbench fonts (OFL) and the app icon |
| `scripts/` | Download, prepare, build and run |

## Build and run

Requirements: Node.js 22, Python 3, git, and VS Code's [build prerequisites](https://github.com/microsoft/vscode/wiki/How-to-Contribute#prerequisites) (on Debian/Ubuntu/Pop!_OS: `build-essential g++ libx11-dev libxkbfile-dev libsecret-1-dev libkrb5-dev`).

```bash
# Quickest: try the extensions inside the VS Code you already have
scripts/try-extension.sh

# Run Cinder from source (first run compiles VS Code, which takes a while)
scripts/dev.sh
scripts/dev.sh --quick     # later runs: rebuild Cinder's extensions only

# Package the app for this machine (output: ../VSCode-<platform>-<arch>)
scripts/build.sh
```

## Tests

```bash
cd extensions/cinder-agent
npm test               # unit tests
npm run test:smoke     # starts a real Claude Code process (uses ANTHROPIC_API_KEY if set)
npm run typecheck
```
